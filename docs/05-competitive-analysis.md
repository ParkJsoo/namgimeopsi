# Competitive-analysis notes

## Why this project still exists

국내에도 식재료 관리·AI 레시피를 시도하는 앱이 있다. 따라서 남김없이의 포트폴리오 가치는 새로운 기능을 주장하는 데 있지 않다. 기존 접근을 조사한 뒤, 사용자가 실제로 반복해야 하는 행동을 좁히고 신뢰 가능한 UX로 구현하는 데 있다.

## Observed competitor directions

| 제품 | 관찰한 방향 |
| --- | --- |
| 냉장고 털기 | 소비기한·재고·영수증 스캔·레시피·공유·장보기 흐름을 폭넓게 제공한다. |
| 냉장고 셰프 | 식재료 등록, 기한 관리, 사진 인식, AI 레시피·상담을 제공한다. 공개 리뷰에서는 재료 탐색·여러 품목 입력·목록 밀도에 대한 불편이 언급된다. |
| 냉고 | 재료 사진 또는 텍스트를 이용한 AI 레시피 추천에 집중한다. |

## Product decision

단순히 기능을 더 추가하지 않는다. 다음 두 경험의 완성도에 집중한다.

### 1. Korean receipt to trusted inventory

영수증의 축약 상품명을 생활 속 식재료 단위로 제안하고, 사용자가 짧게 검수한 결과만 재고에 반영한다.

```text
원문 상품명 → 표준 재료명·수량·보관 위치·권장 소비일 초안 → 확인/수정/제외 → 입고
```

### 2. Leftover-first dinner decision

재료 목록을 많이 보여 주는 대신, 남은 음식과 임박 재료를 먼저 소진하는 현실적인 메뉴를 세 개만 제안한다.

```text
오늘 먼저 먹을 것 → 추천 이유가 있는 메뉴 세 개 → 조리/섭취 완료 → 재고 차감
```

## Implications for the case study

- `AI 영수증 인식` 자체를 차별점이라고 주장하지 않는다.
- AI의 낮은 확신도, 수정 비용, 재고 정합성 문제를 제품 설계의 중심으로 다룬다.
- 남은 배달 음식과 반찬을 재료와 동등하게 관리하는 흐름을 강조한다.
- 기능 수가 아니라 실제 상태 변화까지 완결되는 데모를 우선한다.
