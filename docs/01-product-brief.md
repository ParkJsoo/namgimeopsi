# Product brief

## Product statement

**남김없이**는 장 본 재료와 남은 음식을 빠르게 기록하고, 버리기 전에 오늘 먹을 한 끼를 결정해 주는 1~2인 가구용 AI 식재료 관리 앱이다.

## Portfolio objective

이 프로젝트의 목표는 출시 가능한 모든 기능을 구현하는 것이 아니다. 다음을 보여 주는 완결된 모바일 제품을 만든다.

- 문제를 작은 행동 단위로 정의하는 제품 판단
- AI 결과의 불확실성을 다루는 신뢰 UX
- 상태 변화가 끝까지 이어지는 모바일·백엔드 구현
- 제한된 범위를 정하고 이를 명확하게 설명하는 기술적 판단

## Target user

### 윤서 · 29세 · 1인 가구 직장인

- 평일에는 배달·간편식·간단한 집밥을 섞어 먹는다.
- 주 2~3회 장을 보고 채소, 두부, 고기, 계란 등을 사지만 일부는 잊어버린다.
- 남은 배달 음식과 직접 만든 카레·반찬이 자주 생긴다.
- 퇴근 후 무엇을 먹을지 정하는 일을 귀찮아한다.
- 정확한 g 단위 기록, 매 끼니 기록, 빈번한 알림에는 쉽게 이탈한다.

## Jobs to be done

### Primary job

퇴근 후 저녁을 정해야 할 때, 냉장고의 임박 재료와 남은 음식을 기준으로 지금 먹거나 만들 수 있는 현실적인 한 끼를 빠르게 정하고 싶다. 그래야 식재료를 버리지 않고 메뉴 고민과 추가 장보기를 줄일 수 있다.

### Supporting job

장을 본 직후 영수증을 찍어, 긴 수기 입력 없이 구매품을 믿을 수 있는 재고 목록으로 남기고 싶다.

## Product hypotheses

1. 영수증 기반의 검수형 입고는 수동 입력보다 재고 등록 완료율을 높인다.
2. 임박 재료와 남은 음식에 이유를 붙여 메뉴 3개만 제안하면, 단순 유통기한 알림보다 실제 소비 행동을 높인다.
3. 1~2인 가구는 정확한 중량보다 `있음 / 조금 남음 / 1인분`처럼 생활 단위의 재고 상태를 선호한다.

## MVP requirements

| 영역 | 요구 사항 |
| --- | --- |
| 입고 | 영수증 이미지에서 품목 후보를 만들고, 사용자가 확인·수정·제외 후 재고에 반영한다. |
| 재고 | 보관 위치, 수량, 구매/보관일, 포장 표기일, 권장 섭취 시점을 구분해 저장한다. |
| 남은 음식 | 사진 또는 이름으로 빠르게 등록하고, 기본 보관 시작 시간을 `지금`으로 제안한다. |
| 메뉴 | 임박도와 재료 충족도를 기준으로 최대 세 개의 메뉴를 제안한다. |
| 소비 | 조리 또는 섭취 완료 시 실제 사용량을 확인하고 재고를 차감한다. |
| 신뢰 | AI가 생성한 데이터는 사용자 확정 전까지 재고 원장에 기록하지 않는다. |

## Explicit non-goals

- 모든 식품·사진·수량을 자동으로 정확히 인식하는 것
- 식품 안전을 보장하거나 섭취 가능 여부를 단정하는 것
- 쇼핑·배달·스마트 냉장고 생태계를 통합하는 것
- 대규모 레시피 플랫폼이나 커뮤니티를 만드는 것

## Success signals for a portfolio demo

- 영수증 한 장을 촬영하고 검수해 재고가 갱신되는 흐름이 1분 안에 보인다.
- 홈의 메뉴 추천 이유가 재고 데이터와 일관된다.
- 조리 완료 후 재료 잔량과 홈의 임박 상태가 실제로 바뀐다.
- 낮은 신뢰도의 인식, 빈 재고, 네트워크 오류, 수정·취소 상태가 모두 다뤄진다.
